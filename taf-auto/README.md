# TAF 牛一覧の自動取得と「牛検索」

週に1回、TAF（十勝酪農畜産物生産履歴システム）に**1回だけ**サインインし、
担当している全農家の「在籍牛一覧」CSV を会社のフォルダに取ってきます。
取り終わったら、全農家ぶんをまとめた **牛検索.html** を作ります。
デスクトップの「牛検索」を開いて**耳標の4桁**（TAF の画面に出ている「0722 6」の 0722）を打つと、
その牛の情報がすぐに出ます。

- 農家ごとにログインし直す必要はありません（農家を選ぶ画面に戻って次の農家を選ぶだけ）
- 牛検索.html はファイル1枚で動きます。インターネットにつながっていなくても使えます
- 同じ4桁の牛が何戸かにいるときは、**農家の候補**が並びます。選ぶとその牛の情報が出ます（1頭だけならすぐ出ます。Enter でいちばん上の候補）
- 先週取った分と比べて、**新しく入った牛（生まれた子牛など）**と**分娩日が変わった牛**に青い印が付きます
- 5桁（最後の1桁つき）・10桁ぜんぶ・名号の一部でも探せます。Esc で消えます

## 保存されるもの

```
C:\LIGvets\TAF牛一覧\            ← config.json の「保存先フォルダ」
├─ 牛検索.html                    ← これを開く（デスクトップにショートカットを置きます）
├─ 00001234_十勝 太郎\
│   ├─ 牛一覧_20261005.csv        ← 取った日ごとに残る（TAF から落としたままの形）
│   └─ 牛一覧_最新.csv            ← いつも最新。エクセルからはこちらを開くと楽
└─ 00005678_清水 花子\
    └─ …
```

## はじめに（事務所の Windows PC で1回だけ）

1. **Node.js を入れる**：<https://nodejs.org/ja> から「LTS」を入れる（全部「次へ」で可）
2. この `taf-auto` フォルダを PC の好きな場所に置く（例：`C:\LIGvets\taf-auto`）
3. **`はじめに一度だけ.bat`** をダブルクリック。部品が入り、メモ帳が2つ開きます
   - `.env`：TAF の ID とパスワード（サインイン画面に入れているものと同じ。`farmers\` から書く）。
     **JA ごとに ID が違う**ので、清水町は `_1`、新得町は `_2` のように番号を付けて並べる。毎週、アカウントを順番に使って両方の農家を取ります
   - `config.json`：`保存先フォルダ` を会社のフォルダに書き換える（`\` は `\\` と2つ重ねる）
4. **`今すぐ取る.bat`** で1回試す。全農家ぶん取れて、保存先に `牛検索.html` ができれば成功
5. **`毎週の自動取得を登録.bat`** を動かす。毎週月曜 7:00 に自動で取りに行き、
   デスクトップに「牛検索」のショートカットができます

> ID とパスワードは `.env` にだけ書きます。`.env` と `config.json` は GitHub には上がりません。

## 設定（config.json）

| 項目 | 意味 |
|---|---|
| `保存先フォルダ` | CSV と牛検索.html を置く場所。共有フォルダ（`\\\\サーバー名\\共有\\TAF牛一覧`）でも可 |
| `農家` | `"全部"` なら、農家を選ぶ画面に出る農家をぜんぶ取る。一部だけにしたいときは `[{"生産者コード":"00001234","名前":"十勝 太郎"}]` のように並べる |
| `取らない農家` | 取りに行かない農家の生産者コードを並べる。例：`["00012345"]`。なお、牛一覧からCSVを出せない農家も、農場状況の「経産牛」「未経産牛」の数字から開く一覧を画面から読み取って保存するので、ここに入れなくてよい |
| `画面を出す` | `true` にすると、ブラウザが動く様子が見える（うまくいかないときの確認用） |
| `ブラウザ` | `"msedge"`（PC に入っている Edge を使う）。Chrome なら `"chrome"` |

## うまくいかないとき

- `logs\日付.log` に、どの農家で止まったかが書いてあります
- 止まったときは `logs\` に**その時の画面の写真（.png）と中身（.html）**を残します。
  サイトの作りが変わってボタンが見つからなくなったときは、この2つを送ってもらえれば直せます
- 1戸でつまずいても、残りの農家は取りに行きます。牛検索.html は、取れなかった農家だけ前回の分のままになります
- 牛検索の画面の上に「古くなっています」と出たら、10日以上取れていません
- 自動取得は、その時刻に **PC が起動していて Windows にサインインしている**ときに動きます

## 手直しする人向け

- `taf-download.mjs`：取得の本体（Playwright で Edge を動かす）。ポータル → 酪畜履歴（新しいタブ）→ 農家の丸（`radioSelect`）→ 「変更」（`#BTNCHANGE`）→ 牛一覧（`DNL00`）→ 絞り込みを全部オン → 「表示中リストCSV出力」（`a.csv-output`、POST で届く）の順。牛一覧の絞り込みは前回の状態が残るので、毎回ぜんぶ入れ直している。ボタンは**画面に書いてある文字**で探すので、
  見た目が変わっても文字が同じなら動きます
- `build-viewer.mjs`：CSV（Shift_JIS）を読んで牛検索.html を作る。単独でも `node build-viewer.mjs "保存先"` で作り直せます
- `viewer-template.html`：牛検索の画面のひな形
- `npm test`：TAF に似せた偽のサイトを手元に立てて、取得 → 画面づくり → 4桁で引く、まで通しで確かめる（本物にはつながない）
